# DST 入门指北

一个面向《饥荒：联机版》（Don't Starve Together）的中文入门与机制速查指南。

主要用于手机端快速查询游戏过程中容易忘记或不容易理解的机制，包括：

- 角色特点与技能机制
- 生存、理智、回血等基础知识
- 常用料理、原材料与制作方法
- 四季特点与季节 Boss
- 猪王、小惊吓、切斯特、格罗姆等生物与 NPC
- 皮弗娄牛完整驯化指南
- 月亮科技、天体宝球与换角色机制
- 常用素材来源与用途
- 隐藏机制及世界速查

页面针对手机浏览进行了优化，支持关键词搜索和分类筛选。
